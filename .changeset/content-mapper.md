Add `@utilize/content-mapper`: import `.jsonschema` files as generated Zod, Effect Schema or TypeScript modules through a TypeScript 7.1 content mapper, a Node 24 loader and a Vite/Rollup/Rolldown plugin. The content mapper reuses the existing parser and generators, returns `$ref` files as watched files, and reports JSON and generation errors in the editor.
